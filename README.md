# IQC-CD

Official implementation of **Image-level weakly supervised building change detection based on feature intervention and semantic consensus**.

IQC-CD learns a lightweight multi-scale change query from image-level labels. Spatial supervision is generated by replacing second-temporal features inside irregular regions of unchanged pairs. During inference, the learned visual-change evidence is combined with a frozen SatlasPretrain building prior through harmonic consensus, followed by a five-parameter image-presence gate.

## Method

- Frozen DINOv3 ConvNeXt-Tiny encoder with four-scale dense features
- 41,089-parameter time-symmetric change-query head
- Spatially known negative-feature intervention
- Frozen SatlasPretrain aerial building-instance prior
- Parameter-free harmonic semantic consensus
- Image-presence gate fitted using image-level labels

## Installation

```bash
conda create -n iqccd python=3.11 -y
conda activate iqccd
pip install -r requirements.txt
```

## Pretrained models

- **DINOv3 ConvNeXt-Tiny**: [`timm/convnext_tiny.dinov3_lvd1689m`](https://huggingface.co/timm/convnext_tiny.dinov3_lvd1689m). With `dinov3_weights` set to `null`, `timm` downloads the checkpoint automatically. For offline use, place `model.safetensors` under `weights/` and set the local path in the configuration.
- **SatlasPretrain aerial SwinB**: download [`aerial_swinb_si.pth`](https://huggingface.co/allenai/satlas-pretrain/resolve/main/aerial_swinb_si.pth?download=true) to `weights/aerial_swinb_si.pth`.

The corresponding upstream implementations are available from [DINOv3](https://github.com/facebookresearch/dinov3) and [SatlasPretrain Models](https://github.com/allenai/satlaspretrain_models).

## Datasets and paths

Download [WHU-CD](https://gpcv.whu.edu.cn/data/) and [LEVIR-CD](https://github.com/justchenhao/LEVIR), prepare 224×224 image pairs, and organize them as follows:

```text
IQC-CD/
├── data/
│   ├── WHU-CD/
│   │   ├── T1/
│   │   ├── T2/
│   │   └── masks/
│   └── LEVIR-CD/
│       ├── T1/
│       ├── T2/
│       └── masks/
├── splits/
│   ├── WHU-CD/{train,val,test}.csv
│   └── LEVIR-CD/{train,val,test}.csv
└── weights/
    └── aerial_swinb_si.pth
```

The image names must match the identifiers and relative paths in the included CSV files. Training reads only `id`, `t1`, `t2`, and `label`; masks are opened only by `evaluate.py` for final pixel-level metrics.

Data preparation scripts are included under `splits/`. After placing the original datasets in `data/WHU-CD-raw/` and `data/LEVIR-CD-raw/`, reproduce the 224×224 tiles and CSV files with:

```bash
python splits/prepare_whu_dataset.py
python splits/prepare_levir_dataset.py
```

The WHU-CD script expects `before/before.tif`, `after/after.tif`, and `change label/change_label.tif`. The LEVIR-CD script expects the official `{train,val,test}/{A,B,label}` layout. Use `--help` to override paths or preprocessing settings.

### Data splits

| Dataset | Split | Total | Changed | Unchanged |
|---|---:|---:|---:|---:|
| WHU-CD | Train | 7,685 | 1,707 | 5,978 |
| WHU-CD | Validation | 725 | 181 | 544 |
| WHU-CD | Test | 870 | 203 | 667 |
| LEVIR-CD | Train | 11,125 | 4,554 | 6,571 |
| LEVIR-CD | Validation | 1,600 | 636 | 964 |
| LEVIR-CD | Test | 3,200 | 1,372 | 1,828 |

WHU-CD uses a row-wise spatial split with an 80/10/10 target ratio and a one-tile isolation gap between adjacent subsets. LEVIR-CD follows the official train/validation/test scene partition before tiling. The included manifests reproduce the splits used in the reported experiments.

## Training and evaluation

### WHU-CD

```bash
python train.py --config configs/whu.json --device cuda
python evaluate.py --config configs/whu.json --device cuda
```

### LEVIR-CD

```bash
python train.py --config configs/levir.json --device cuda
python evaluate.py --config configs/levir.json --device cuda
```

Checkpoint selection uses validation image-level ROC-AUC. The image-presence gate is fitted on a fixed 1,024-pair subset of the training split. `train.py` saves the query head and image gate under `runs/whu/` or `runs/levir/`; `evaluate.py` writes the test metrics to the same directory.

## Inference

```bash
python predict.py path/to/T1.png path/to/T2.png \
  --config configs/whu.json \
  --checkpoint-dir runs/whu \
  --output outputs/example \
  --device cuda
```

The output directory contains the two building-occupancy maps, semantic support, change-query map, consensus probability, binary change mask, and image-level probability.
